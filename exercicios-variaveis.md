# Exercícios de Variáveis em PHP

1. **Exercício 1**  
   Crie uma variável e atribua a ela um valor inteiro. Exiba o tipo da variável usando `gettype()`.

2. **Exercício 2**  
   Declare uma variável com um valor string e use `var_dump()` para exibir seu conteúdo e tipo.

3. **Exercício 3**  
   Crie um array com três números inteiros e exiba o tipo da variável usando `gettype()`.

4. **Exercício 4**  
   Verifique se uma variável é um array usando a função `is_array()`.

5. **Exercício 5**  
   Altere o tipo de uma variável float para inteiro usando `settype()` e exiba o novo tipo.

6. **Exercício 6**  
   Declare uma variável sem atribuir valor e use `var_dump()` para verificar seu conteúdo.

7. **Exercício 7**  
   Crie um array associativo com três pares chave-valor e exiba o conteúdo usando `var_dump()`.

8. **Exercício 8**  
   Declare uma variável com valor booleano e exiba seu tipo usando `gettype()`.

9. **Exercício 9**  
   Use `settype()` para converter uma string em um número inteiro e exiba o novo valor.

10. **Exercício 10**  
    Crie uma variável com valor nulo e verifique seu tipo usando `gettype()`.

11. **Exercício 11**  
    Declare um array com valores de diferentes tipos (int, string, bool) e exiba o conteúdo com `var_dump()`.

12. **Exercício 12**  
    Verifique se uma variável é do tipo string usando a função `is_string()`.

13. **Exercício 13**  
    Declare uma variável com um número decimal e converta-a para string usando `settype()`.

14. **Exercício 14**  
    Crie um array numérico e use um loop `foreach` para exibir cada valor.

15. **Exercício 15**  
    Declare uma variável com valor inteiro e verifique se ela é do tipo inteiro usando `is_int()`.

16. **Exercício 16**  
    Crie uma variável com valor booleano e altere seu tipo para string usando `settype()`.

17. **Exercício 17**  
    Declare uma variável com uma string e verifique se ela é do tipo booleano usando `is_bool()`.

18. **Exercício 18**  
    Crie um array vazio e verifique se ele é um array usando `is_array()`.

19. **Exercício 19**  
    Declare uma variável com valor inteiro e altere seu tipo para float usando `settype()`.

20. **Exercício 20**  
    Crie uma variável com valor string e use `strlen()` para exibir o comprimento da string.
