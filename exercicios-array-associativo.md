# Exercícios: Arrays associativos


## Exercício 1: Array Associativo de Produtos
Crie um array associativo para representar um produto com as chaves `nome`, `preco` e `quantidade`. Exiba as informações do produto.

## Exercício 2: Atualizando Valores
Utilize o array associativo do exercício anterior e atualize o valor da chave `preco`. Exiba o novo valor.

## Exercício 3: Verificando a Existência de uma Chave
Crie um array associativo com informações de um usuário (`nome`, `email`, `idade`). Verifique se a chave `telefone` existe no array.
