# Exercícios com $_GET e $_POST no PHP

1. **Exercício 1: Saudação com $_GET**
   - Crie uma página PHP que receba um nome via `$_GET` e exiba uma mensagem de saudação personalizada.

2. **Exercício 2: Soma de dois números com $_GET**
   - Desenvolva um script PHP que receba dois números via `$_GET`, some-os e exiba o resultado.

3. **Exercício 3: Formulário de login com $_POST**
   - Crie um formulário HTML que envie um nome de usuário e senha via `$_POST` para um script PHP que valide se o nome de usuário é "admin" e a senha é "1234".

4. **Exercício 4: Cadastro de usuário com $_POST**
   - Desenvolva um formulário que receba nome, e-mail e idade via `$_POST` e exiba os dados enviados em uma nova página.

5. **Exercício 5: Verificação de número par ou ímpar com $_GET**
   - Crie um script PHP que receba um número via `$_GET` e informe se ele é par ou ímpar.

6. **Exercício 6: Calculadora simples com $_POST**
   - Construa um formulário que receba dois números e uma operação (soma, subtração, multiplicação ou divisão) via `$_POST` e exiba o resultado da operação.
